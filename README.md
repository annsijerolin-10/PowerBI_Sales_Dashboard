# 📊 Power BI Sales Performance Dashboard

This project showcases a Sales Performance Dashboard built using Power BI. It integrates sales data from 2014 to 2017 and visualizes key business metrics like total revenue, gross profit, unit sales, and sales trends across products, categories, time, and geography.

---

## 📂 Project Overview

**Objective:**  
To create a dynamic and interactive dashboard to analyze multi-year sales data and uncover actionable insights for business decision-making.

**Data Sources:**
- Sales data (2014–2017): `sales 2014.csv`, `sales 2015.csv`, `sales 2016.csv`, `sales 2017.csv`
- Dimension tables: `Categories.xlsx`, `SubCategories.xlsx`, `Product.csv`, `SalesRep.xlsx`, `Geography` (from Power BI)

---

## 📈 Key Visuals

- KPI Cards: Total Revenue, Gross Profit, and Units Sold
- Pie and Bar Charts: Revenue by Subcategory and Product
- Waterfall Chart: Year-over-Year revenue change
- Line Charts: Monthly and Quarterly performance trends
- Top 5 Sales Reps panel
- Slicers for Country, Year, and Month filtering

---

## 🛠 Tools & Technologies

- Power BI
- Microsoft Excel
- CSV & Excel integration
- DAX for calculated fields and KPIs
